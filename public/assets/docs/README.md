# Documentation Assets

This directory is reserved for static assets (e.g., screenshots, diagrams, and illustrations) used exclusively in the application's documentation, such as the Changelog or Help/Manual screens.

**Guidelines:**
- Please keep image file sizes optimized (e.g., use WebP or heavily compressed PNGs).
- Use descriptive filenames (e.g., `help-dashboard-overview.webp`).
- Do not store general UI assets (icons, logos) here.
